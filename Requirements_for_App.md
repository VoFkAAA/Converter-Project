## Требования
<br>
 
Одно поле с маской __.__._____. 

Слева от поля текст "Введите дату"
Второй строчкой текст "(только цифры)"

В поле плейсхолдер: ДД.ММ.ГГГГ

Точки проставляются автоматически.

В поле (справа) есть кнопка "Х", позволяющая очистить поле.

Допустимые символы:  
Только цифры. Точки проставляются автоматически.

Не должно быть значения "00" для дня и месяца и "0000" - для года. Допустимый диапазон значений: 
- день: 01 - 31
- месяц: 01-12
- год: 1900 - 2100

!!! Учесть диапазон значений для дней:
- для января, марта, мая, июля, августа, октября, декабря: 01 - 31
- для апреля, июня, сентября, ноября: 01 - 30
- для февраля високосного года: 01 - 29
- для февраля НЕвисокосного года: 01- 28
- для февраля 1900 и 2100 годов: 01 - 28
- для февраля 2000 года: 01 - 29

В качестве крайних дат для года будут: 
- 01.01.1900 
- 31.12.2100 

Если введена только одна цифра, то перед ней автоматически НЕ проставляется "0" (ноль).

Валидация происходит после ввода значения в поле (при снятии фокуса). Если введены невалидные значения/символы - отображается валидационное сообщение (красным цветом) об ошибке - "Некорректная дата". 

Есть кнопка "Конверировать". После нажатия (при корректно введённой дате) отображается день недели, соответствующий дате. При этом дополнительно появляется кнопка "Теперь следующая дата?" После нажатия на кнопку "Теперь следующая дата?" поле ввода очищается, а день недели - исчезает. 

Дни недели:
- понедельник
- вторник
- среда
- четверг
- пятница
- суббота
- воскресенье

Кнопка "Конвертировать" неактивна, если дата не введена полностью и/или введена некоррекная дата.

При обновлении страницы данные не сохраняются.

Кнопка (переключатель) "Тёмная тема / Светлая тема" в правом верхнем углу.

Между кнопками и полем можно переключаться кнопкой "Tab".
Внутри самого поля ввода даты можно переключаться кнопкой Tab между блоками день / месяц / год. 

Данные в поле можно: 
- копировать (в т.ч. частично), 
- вставить (в т.ч. частично), 
- редактировать (в т.ч. частично), 
- удалять (в т.ч. частично)
